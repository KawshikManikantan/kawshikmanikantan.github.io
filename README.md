# kawshikmanikantan.github.io

Source for [kawshikmanikantan.github.io](https://kawshikmanikantan.github.io/), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme.

- `_pages/about.md` – home page
- `_bibliography/papers.bib` – publications
- `_data/cv.yml` and `assets/pdf/CV.pdf` – CV page and PDF
- `_news/` – updates shown on the home page
- `_pages/MEI.md` – project page for Major Entity Identification

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.
